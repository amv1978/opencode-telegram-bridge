# Changelog

## 0.2.1 — 2026-11-19

Стилистика и поведение тем; API и конфиг не менялись.

### Изменения

- Голос: расшифровка приходит rich-сообщением в стиле зеркальных сообщений —
  цитата `> 💠 **Расшифровка · голос**`, текст построчно и `⏱ … с`; если rich-режим
  недоступен, отправляется обычный текст. Задача в сессию уходит как раньше.
- Форум: создание темы сразу создаёт сессию OpenCode с названием темы и привязывает
  её (если привязки ещё нет), в теме появляется короткая цитата «🆕 Сессия создана».
  Первое сообщение в уже существующей теме без привязки по-прежнему создаёт сессию
  по тексту сообщения. Закрытие и удаление темы сессию не завершают — кода, удаляющего
  сессии, нет.

### Версии

- Правила смены версии не изменились: `package.json`, `desktop/package.json`,
  `installer/ocbridge.iss` (`#define AppVersion`), `cli/cli.csproj` (Version /
  FileVersion / AssemblyVersion / InformationalVersion) и `Program.Version`
  в `cli/Program.cs`. Установщик: `dist/ocbridge-setup-0.2.1.exe`.

## 0.2.0 — 2026-11-19

Интерфейс, установка и голос.

### Добавлено

- Electron-оболочка: окно, трей с индикатором состояния (зелёный/жёлтый/красный),
  меню, «Открыть в браузере», автозапуск, запоминание размеров окна.
- Синхронизация темы с заголовком окна: фон и цвет символов title bar.
- CLI `ocbridge-cli` на .NET 10: `status`, `start/stop/restart`, `sessions`,
  `logs`, `config get/set`, `autostart`, `doctor`, `version`, `help`.
- Установщик Inno Setup: простой и расширенный режим, локализация RU/EN,
  запись `ui.lang`, завершение запущенных копий по пути, ffmpeg в комплекте.
- Голосовые сообщения: OGG/Opus → ffmpeg → WAV 16 kHz → HEX CLI, с кнопкой
  включения Labs-флага `transcribe-files`.
- Темы OpenCode и Matrix, схемы system/light/dark; язык интерфейса system/ru/en.
- Футер ответа: `⏱` длительность, `⚡` tok/s, `🧠` контекст — по формуле OpenCode.
- Двусторонняя синхронизация имени: переименование темы обновляет сессию и наоборот.
- Обработка удалённой темы: привязка очищается, ответ уходит в корень чата.
- Зеркалирование запросов из Desktop/TUI в привязанный чат.

### Изменено

- Формат ответов — Telegram rich messages (нативный Markdown), с откатом на HTML.
- Сборка данных в `%APPDATA%\opencode-telegram-bridge\` для установленных версий,
  с переносом старых `config.json`/`state.json` из папки exe.

## 0.1.0 — 2026-11-10

Первый рабочий мост.

- Подключение к общему сервису OpenCode 2.x, те же сессии, что в Desktop/TUI.
- Режимы `private`, `topics`, `both`; форум-группа, тема = сессия.
- Стриминг ответов правками одного сообщения, настройка троттлинга.
- Команды `/new`, `/sessions`, `/attach`, `/topic`, `/chatid`, `/status`,
  `/model`, `/agent`, `/stop`, `/fmt`, `/detach`.
- Кнопки подтверждения разрешений (`once` / `always` / `reject`).
- Локальная веб-панель `127.0.0.1:7788`: токен, режим, allowlist, журнал.
- Фото и документы до 20 МБ в сессию, HTML-разметка ответов.
- Обход блокировки Telegram: пиннинг IP и прокси.
