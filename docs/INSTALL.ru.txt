OpenCode Telegram Bridge — установка и первый запуск

1. После установки приложение запускается само (окно + значок в трее).
2. Если токен не был указан в установщике, откройте «Настройки → Telegram»
   в окне приложения и вставьте его (при первом запуске есть отдельная форма).
3. Напишите боту /start в Telegram — вы станете администратором.
4. Темы: создайте группу, включите «Темы», добавьте бота администратором
   с правом «Управление темами», затем отправьте /chatid в группе.
5. Отправьте задачу в личный чат или в тему. /fmt показывает форматирование.
6. Повторный запуск установщика сохраняет все прошлые выборы (способ установки,
   папку, автозапуск, режим, язык, ID чата с темами); сохранённый токен
   показывается маской и никогда не пишется в installer.json.

Трей: статус / запуск / остановка / настройки / журнал / автозапуск / выход
CLI: ocbridge-cli.exe help
Данные: %APPDATA%\opencode-telegram-bridge\ (config.json, state.json, bridge.log)
