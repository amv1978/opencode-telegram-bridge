OpenCode Telegram Bridge — install / установка

EN
1. The app starts after install (window + tray).
2. If the token was not set in the installer, open Settings in the tray and paste it.
3. Write /start to the bot in Telegram — you become the admin.
4. Topics: create a group, enable Topics, add the bot as admin with "Manage topics",
   then send /chatid in the group.
5. Send a task in a private chat or a topic. /fmt shows formatting.

RU
1. После установки запускается приложение (окно + трей).
2. Если токен не указан в установщике — откройте «Настройки» в трее и вставьте его.
3. Напишите боту /start — вы станете администратором.
4. Темы: создайте группу, включите «Темы», добавьте бота админом с правом
   «Управление темами», затем отправьте в группе /chatid.
5. Пишите задачу в личку или в тему. /fmt — пример форматирования.

Tray / Трей: status · start/stop · settings · log · autostart · quit
CLI: ocbridge-cli.exe help
